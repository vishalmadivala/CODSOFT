# Task 4 — Rock-Paper-Scissors Game

**CodSoft Python Programming Internship**

## Description
A command-line Rock-Paper-Scissors game where the user plays against the
computer. The computer's choice is randomly generated, the winner of each
round is determined by classic rules, and scores are tracked across
multiple rounds until the user chooses to stop.

## Features
- User input: rock, paper, or scissors (also accepts shorthand r/p/s)
- Random computer choice
- Round-by-round result display
- Running score tracker (user vs. computer)
- Play-again loop with a final summary at the end

## Rules
- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock

## Requirements
- Python 3.7+
- No external libraries needed (see `requirements.txt`)

## How to Run
```bash
python rock_paper_scissors.py
```
