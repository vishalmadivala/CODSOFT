# Task 5 — Contact Book

**CodSoft Python Programming Internship**

## Description
A command-line Contact Book application for storing and managing personal
contacts. Each contact includes a name, phone number, email, and address.
Contacts are saved persistently to a local `contacts.json` file.

## Features
- Add a new contact with full details
- View all contacts (name + phone quick list)
- Search contacts by name or phone number
- Update existing contact details
- Delete a contact
- Persistent storage using JSON (no database required)

## Requirements
- Python 3.7+
- No external libraries needed (see `requirements.txt`)

## How to Run
```bash
python contact_book.py
```

Then follow the on-screen menu:
```
1. View all contacts
2. Add contact
3. Search contact
4. Update contact
5. Delete contact
6. Exit
```

## Files
| File | Description |
